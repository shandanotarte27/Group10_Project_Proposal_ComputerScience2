# 📊 KiloWatt — Household Electricity Consumption and Cost Analysis

This repository contains KiloWatt, a Python-based household electricity consumption, cost analysis, and usage simulation system. It allows users to manage appliance records, calculate estimated electricity consumption and expenses, analyze usage patterns, compare appliances, and simulate changes in operating hours.

# 📂 Repository Structure
- `/data` → Contains JSON files for persistent storage of appliance records and electricity rate settings.
* `/docs` → Contains the project proposal, wireframe, flowchart, and related documentation.
* `main.py` → Contains the main Python program and menu system.
* `README.md` → Project introduction and overview.

# Instructions:
- Record and manage household appliance data, including wattage, quantity, category, and daily operating hours.
- Calculate estimated daily and monthly electricity consumption and costs.
- Analyze household electricity usage through rankings, percentages, category breakdowns, and summaries.
- Compare two appliances and simulate hypothetical changes in operating hours.
- Save and load appliance records and electricity rate settings using JSON files.

# Getting Started
- Open the repository and locate the project files.
- Run `main.py` using Python.
- Navigate through the menu to manage appliance records, calculate consumption, analyze usage, compare appliances, or simulate usage.
- Follow the displayed instructions to enter data and view results.
